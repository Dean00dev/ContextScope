# ContextScope v0.2.0 — Try It in 30 Seconds

ContextScope v0.2.0 is an adoption-focused release that makes the existing five-agent instruction analysis substantially easier to evaluate and add to a repository.

## Highlights

- run directly with `npx --yes github:Dean00dev/ContextScope ...` — no global install required;
- new five-minute quickstart from first command to CI;
- clearer first-run examples for `doctor`, `scan`, `matrix`, `explain`, and `diff`;
- GitHub Action examples updated for the v0.2.0 release tag;
- improved README discoverability and release visibility;
- package, CLI and lockfile versions synchronized at 0.2.0.

## Still deliberately boring in the best ways

- zero runtime dependencies;
- no API key;
- no model calls;
- no telemetry;
- no hidden semantic-equivalence claims;
- explicit `exact`, `partial`, and `conditional` certainty.

## Fastest test drive

```bash
npx --yes github:Dean00dev/ContextScope doctor
npx --yes github:Dean00dev/ContextScope scan
npx --yes github:Dean00dev/ContextScope matrix src/auth/login.ts
```

Replace the example path with a real source path in your repository.

## Scope

This release intentionally does not pretend to ship the roadmap's PR-impact engine early. The underlying analysis semantics remain the v0.1 design; v0.2 focuses on making that useful core easier to discover, evaluate, clone, and adopt.
