# ContextScope v0.1.0 — Effective Agent Context Visibility

ContextScope v0.1.0 is the first public release of an offline CLI and GitHub Action for reconstructing repository-provided coding-agent instruction surfaces.

## Highlights

- path-aware profiles for Codex, Claude Code, GitHub Copilot, Cursor and Gemini CLI;
- `explain`, `matrix`, `diff`, `scan`, and `doctor` commands;
- explicit `exact`, `partial`, and `conditional` certainty instead of guessed runtime behaviour;
- repository-local import validation and symlink escape protection;
- exact-line instruction parity comparisons;
- JSON, Markdown, SARIF and JUnit evidence outputs;
- zero runtime dependencies and no model/API calls;
- Node 20/24 CI across Linux, macOS and Windows;
- GitHub Action support.

## Core boundary

ContextScope reports repository-provided instruction structure. It does not inspect hidden system prompts, personal/global instructions, model memory, or whether a model actually obeyed an instruction.
